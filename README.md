# My Melody's Haunted Mansion

Static site (HTML/CSS/JS, no build). Answers are emailed via Web3Forms.

## Edit content
Everything (trivia, dates, times, prizes, Josh's high score, form key) is in `js/config.js`.

## Run locally
```
python3 -m http.server 8123
# open http://localhost:8123
```

## Deploy to GitHub Pages
1. Create a GitHub repo and push these files to `main`.
2. Repo Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Open `https://<username>.github.io/<repo>/`.
4. In the Web3Forms dashboard, set the form's website URL to that address.
5. Submit one real test on your phone and confirm the email arrives before sending her the link.
